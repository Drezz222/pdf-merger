How to combine a PDF with images

  1. Open the visual Merge workspace and select one or more PDF, JPG, PNG, or WebP files from your device.
  2. Wait for the page and image previews. Each image becomes one output page.
  3. Drag a page on desktop, or use the Move earlier and Move later controls on touch or keyboard, until every page is in the right place.
  4. Rotate an individual page in 90-degree steps or remove a page you do not want.
  5. Enter a clear file name, choose Merge & download, and save the resulting PDF.

Visual control before export

A file list alone does not show where each image will land. fold.pdf expands PDFs into page thumbnails and displays images as page cards, so the output order is visible before export. Page-level controls work across source-file boundaries: an image can sit between page 2 and page 3 of an existing PDF, and an unwanted source page can be removed without editing the original file.

Rotation is stored only for the new output. Your original local files are not modified. JPG and PNG files are embedded directly where possible; WebP is converted in the browser for PDF compatibility.

Local files and remote imports

Files you select from your device are processed in your browser. If you choose the optional URL or Google Drive importer, the link and file pass through the fold.pdf serverless proxy and hosting provider before the file returns to the browser. Download the remote file first and select it locally when privacy is the priority. See the privacy details.

PDF and image FAQ

Which image formats are supported?

The workspace accepts JPG/JPEG, PNG, and WebP images. TIFF, HEIC, SVG, and other formats are not advertised because browser decoding and safe PDF conversion are not consistent.

Can I put an image between two PDF pages?

Yes. Every PDF page and image appears as an individual output card, so you can move an image to any position.

Can I rotate an image or PDF page?

Yes. Use the rotate control on an individual output page. Rotation changes the new PDF, not your source file.

Are images stretched to fill a page?

Each image keeps its aspect ratio. The output page is created from the image dimensions, then any selected page rotation is applied.

Can I delete pages before combining?

Yes. Remove any PDF page or image card before export; only the remaining ordered pages are included.
