How to split a PDF

  1. Open fold.pdf and add the PDF you want to split.
  2. Enter the page range you want, such as 1-3 or 5.
  3. Add more ranges if needed, or choose auto-split to make one PDF per page.
  4. Download the resulting files.

PDF splitter FAQ

Can I extract only a few pages?

Yes. Define custom ranges such as 1-3, 5, or other page selections.

Can I split every page automatically?

Yes. Auto-split creates one output PDF for each page of the source document.

Do I need to install software?

No. fold.pdf runs as a web application in your browser.
