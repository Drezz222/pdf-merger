Privacy-first workflow

Your local documents stay local.

When you add files directly from your device, the PDF processing happens in your browser using client-side PDF libraries. That means those local files do not need to be uploaded to a document-processing server just to merge them.

What about URL and Drive imports?Those features need to fetch the remote file before it can be added to the workspace. If privacy is your priority, download the document first and add it directly from your device.

FAQ

Common PDF merger questions.

Is fold.pdf free to use?

Yes. The current PDF merge and split tools can be used without creating an account.

Can I change the order of PDF pages before merging?

Yes. Add your files, preview the pages in the workspace, then drag pages into the order you want before downloading the merged PDF.

Can I merge images with PDF files?

Yes. The tool supports PDF files plus common image formats including JPG, PNG and WEBP, with additional image formats supported by the browser workflow.

Do files from my computer get uploaded?

Files selected directly from your device are processed in the browser. URL and Google Drive imports work differently because the remote file first needs to be fetched.

Can I split a PDF too?

Yes. Switch to the split workflow to choose page ranges, or automatically split a PDF into one file per page.
